使用说明

1. 在手机浏览器中打开本文件，建议使用 Safari 或 Chrome。
2. 创建 GitHub Fine-grained Token，Repository access 只选 huqingci1234/resource-hub；Repository permissions 中 Contents 设为 Read and write。
3. 粘贴令牌并连接，添加或修改资源。
4. 点击“发布到 GitHub”，等待成功提示。网站通常需要一点时间完成 Pages 更新。

注意：令牌相当于仓库写入钥匙。不要将本管理文件连同令牌截图或分享给他人。若怀疑令牌泄露，请立即到 GitHub 撤销。
